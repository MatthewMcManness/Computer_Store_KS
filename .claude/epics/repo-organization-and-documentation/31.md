```markdown
## Project Overview

Computer Store KS is a website for a computer repair shop featuring:
- Public-facing website (Next.js)
- Admin gallery management system
- Flyer generator for promotions
- Contact form with email notifications

## Architecture

### Active Code
- `src/` - Next.js 14 application (TypeScript, Tailwind)
- `api/` - Express.js backend for gallery operations
- `public/` - Static assets
- `.claude/` - AI development workflow (CCPM)

### Archived Code
- `_archive/` - Deprecated static HTML site and legacy docs
  - Do NOT reference files in `_archive/` for current development
  - This code is preserved for historical reference only

## Key Files

### Frontend (src/)
- `src/app/` - Next.js App Router pages
- `src/components/` - React components
- `src/lib/auth.ts` - Authentication logic
- `src/lib/github.ts` - GitHub API integration

### Backend (api/)
- `api/gallery-api.js` - Express server for gallery CRUD

### Configuration
- `.env` - Environment variables (not committed)
- `.env.example` - Example environment config
- `next.config.mjs` - Next.js configuration
- `tailwind.config.js` - Tailwind CSS config

## Development Workflow

1. Run `bun install` to install dependencies
2. Copy `.env.example` to `.env` and configure
3. Run `bun run dev` for development
4. Run `bun run build` before committing

## Important Patterns

- Use TypeScript strict mode
- Components in `src/components/` organized by feature
- API routes in `src/app/api/`
- Use Tailwind for styling (no separate CSS files)

## Project Management

This project uses CCPM (Claude Code Project Management):
- PRDs in `.claude/prds/`
- Epics in `.claude/epics/`
- Use `/pm:*` commands for project workflow
```
