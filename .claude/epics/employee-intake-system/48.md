# Task: Ticket Step & Success

## Description
Build the final two steps of the intake wizard: ticket creation (capturing "Customer states:" description) and success confirmation with ticket number. Includes option to start a new intake.

## Acceptance Criteria
- [ ] Shows customer name and device info (read-only summary)
- [ ] Large text area for "Customer states:" issue description
- [ ] Submit button creates ticket in RepairShopr
- [ ] Loading state during submission
- [ ] Success screen shows ticket number prominently
- [ ] Success screen shows summary of what was created
- [ ] "Start New Intake" button resets wizard
- [ ] "View Ticket" link (optional - opens RepairShopr)

## Technical Details
- **Components**:
  - `src/components/admin/intake/TicketStep.tsx`
  - `src/components/admin/intake/SuccessStep.tsx`
- **API**: `POST /api/repairshopr/tickets`

### Ticket Creation Payload
```typescript
const ticketData = {
  customer_id: customer.id,
  asset_id: device?.id,
  subject: `Customer states: ${description.substring(0, 50)}...`,
  problem_type: 'Repair',  // or configurable
  status: 'New',
  comments: [{
    subject: 'Initial Intake',
    body: `Customer states: ${description}`,
    tech: employeeName,
```
