# Task: Device Step

## Description
Build the device selection/creation step where employees either select an existing device for a returning customer or create a new device. Collects brand, type (dropdown), and model.

## Acceptance Criteria
- [ ] Show customer's existing devices (if any)
- [ ] Each device shows: type, brand, model
- [ ] "Select" button to choose existing device
- [ ] "Add New Device" button always visible
- [ ] New device form: Brand, Type (dropdown), Model
- [ ] Device types: Desktop, Laptop, Tablet, Phone, Other
- [ ] Creates device in RepairShopr linked to customer
- [ ] Proceeds to Ticket step on selection/creation

## Technical Details
- **Component**: `src/components/admin/intake/DeviceStep.tsx`
- **API**:
  - `GET /api/repairshopr/customers/[id]/assets` (list devices)
  - `POST /api/repairshopr/assets` (create device)
