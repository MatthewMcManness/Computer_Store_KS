# Task: Add Role-Based Middleware

## Description

Enhance the existing middleware to support role-based access control, restricting certain routes based on user role from the session.

## Acceptance Criteria

- [ ] Update `src/middleware.ts` with role-based route protection
- [ ] Define route permission matrix (which roles can access which routes)
- [ ] Return 403 Forbidden for unauthorized access attempts
- [ ] Redirect to appropriate page when access denied
- [ ] Log unauthorized access attempts

## Technical Details

### File Location
`src/middleware.ts`

### Route Permission Matrix
```typescript
const routePermissions: Record<string, string[]> = {
  '/admin': ['admin', 'employee', 'limited'],       // Dashboard - all roles
  '/admin/gallery': ['admin', 'employee'],          // Gallery management
  '/admin/gallery/new': ['admin', 'employee'],      // Create gallery items
  '/admin/settings': ['admin'],                      // Admin-only settings
  // Add more routes as needed
};

// Default: require authentication but allow any role
const DEFAULT_ALLOWED_ROLES = ['admin', 'employee', 'limited'];
```

### Implementation Approach
```typescript
export async function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  // Check if accessing admin routes
  if (pathname.startsWith('/admin') && !pathname.startsWith('/admin/login')) {
    const session = request.cookies.get(SESSION_COOKIE_NAME);

    if (!session?.value) {
      // Not authenticated - redirect to login
      return NextResponse.redirect(new URL('/admin/login', request.url));
    }

    // Get user role from session store
    const userRole = await getUserRoleFromSession(session.value);

    if (!userRole) {
      // Invalid session - redirect to login
      return NextResponse.redirect(new URL('/admin/login', request.url));
    }

    // Check role permission
    const allowedRoles = routePermissions[pathname] || DEFAULT_ALLOWED_ROLES;
    if (!allowedRoles.includes(userRole)) {
      // Log unauthorized attempt
      console.log(`[AUTH] Unauthorized access attempt: ${pathname} by role ${userRole}`);
      // Redirect to dashboard with error
      return NextResponse.redirect(new URL('/admin?error=unauthorized', request.url));
    }
  }

  return NextResponse.next();
}
```

### Considerations
- Middleware runs on edge, so session lookup must be fast
- Consider caching role in cookie (encrypted) to avoid session store lookup
- Or use JWT-style token with role embedded
