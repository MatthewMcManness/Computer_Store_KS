# Task: Employee Onboarding

## Description
Create admin UI for onboarding new employees. Admin enters employee email, selects role (admin/technician/receptionist), links to RepairShopr user ID, and system sends password setup email.

## Acceptance Criteria
- [ ] Admin can access employee management at `/admin/employees`
- [ ] Form to create new employee with email, role, RepairShopr user ID
- [ ] Supabase creates user and sends "Set your password" email
- [ ] Password setup link expires after 24 hours
- [ ] Employee list shows all employees with their roles
- [ ] Admin can edit employee roles (except their own)

## Technical Details

**New Pages:**
- `src/app/admin/employees/page.tsx` - Employee list
- `src/app/admin/employees/new/page.tsx` - Create employee form

**API Routes:**
- `POST /api/admin/employees` - Create employee
- `GET /api/admin/employees` - List employees
- `PUT /api/admin/employees/[id]` - Update employee role

**Onboarding Flow:**
1. Admin fills form: email, role, RepairShopr user ID
2. API creates Supabase Auth user with Supabase Admin API
3. Supabase sends invite email (password setup)
4. API creates user_profile record
5. Employee clicks email link → sets password → can log in

**Role Validation:**
- Only admins can access this feature
- Admins cannot demote themselves
- At least one admin must always exist

**Files affected:**
- `src/app/admin/employees/page.tsx` (new)
- `src/app/admin/employees/new/page.tsx` (new)
- `src/app/api/admin/employees/route.ts` (new)
