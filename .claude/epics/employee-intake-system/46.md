# Task: Customer Form Step

## Description
Build the customer creation form with support for both individual and business customers. Includes all required fields, validation, and portal password setup. Creates customer in RepairShopr AND Supabase account.

## Acceptance Criteria
- [ ] Toggle between Individual and Business customer types
- [ ] Individual: First name, Last name, Email, Phone, Address (optional)
- [ ] Business: Business name search/create, then contact fields
- [ ] Portal password field (required for new customers)
- [ ] Password confirmation field
- [ ] Form validation with inline error messages
- [ ] Creates customer in RepairShopr on submit
- [ ] Creates Supabase portal account with password
- [ ] Shows existing customer's Supabase account status (for returning customers)
- [ ] Proceeds to Device step on success

## Technical Details
- **Component**: `src/components/admin/intake/CustomerFormStep.tsx`
- **API**: `POST /api/repairshopr/customers`

### Business Customer Flow
1. Search for existing business
2. If not found, create new business (name, address, phone)
3. Create contact linked to business_id
4. Same portal password setup

### Validation Rules
- Email: Valid format, unique in RepairShopr
- Phone: Valid format (flexible - 10 digits minimum)
- Password: Minimum 8 characters
- Confirm password: Must match password
