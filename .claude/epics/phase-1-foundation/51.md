# Task: Supabase Auth Configuration

## Description
Configure Supabase Auth for email/password authentication, set up custom email templates via Resend SMTP, and configure session expiration settings for different user types.

## Acceptance Criteria
- [ ] Email/password provider enabled in Supabase
- [ ] Custom SMTP configured with Resend
- [ ] Email templates customized (verification, password reset, magic link)
- [ ] Session expiration configured (8 hours employees, 30 days customers)
- [ ] Rate limiting configured (5 attempts per 15 min)

## Technical Details

**Supabase Dashboard Configuration:**
1. Authentication > Providers > Email enabled
2. Authentication > Email Templates customized
3. Settings > SMTP > Resend configuration

**Email Templates to customize:**
- Confirm signup
- Reset password
- Magic link
- Invite user (for employee onboarding)

**Session Settings:**
- JWT expiry: 3600 seconds (1 hour)
- Refresh token rotation enabled
- Custom session handling in middleware will extend for employees/customers differently

**Resend SMTP Settings:**
- Host: smtp.resend.com
- Port: 465
- Username: resend
- Password: (from RESEND_API_KEY)

**Files affected:**
- `.env.example` (add SMTP vars documentation)
