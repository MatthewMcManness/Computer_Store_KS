## Design Philosophy

When creating web interfaces and themes, follow these principles:

1. **Bold Aesthetic Commitment**: Choose a clear design direction before coding
2. **Distinctive Design**: Avoid generic AI aesthetics
3. **Typography**: Use characterful fonts (avoid Inter, Roboto, Arial)
4. **Color**: Commit to cohesive palettes with dominant colors and sharp accents
5. **Motion**: Strategic animations for high-impact moments (CSS-first)
6. **Composition**: Asymmetry, overlap, unexpected layouts
7. **Details**: Contextual effects, textures, atmospheric depth
