# Task: Create flyer generator utility with standard templates

## Description
Create `src/lib/flyer-generator.ts` that generates print-ready HTML flyers from GalleryComputer data. The generated HTML must visually match the existing `Sales Cards/Desktop_sales-flyer.html` and `Sales Cards/Laptop_sales-flyer.html` templates exactly.

## Acceptance Criteria
- [ ] Function `generateFlyer(computer: GalleryComputer): void` exported
- [ ] Selects desktop template when `computer.type === 'desktop'`
- [ ] Selects laptop template when `computer.type === 'laptop'`
- [ ] Extracts specs with flexible label matching (e.g., "Memory" or "RAM")
- [ ] Maps data correctly: name, processor, memory, storage, graphics/display, price, warranty
- [ ] Inlines CSS from `sales-flyer.css` for print reliability
- [ ] Opens generated HTML via blob URL in new browser tab
- [ ] Generated flyer is visually identical to manually-edited template

## Technical Details
- Create new file: `src/lib/flyer-generator.ts`
- Reference templates: `Sales Cards/Desktop_sales-flyer.html`, `Sales Cards/Laptop_sales-flyer.html`
- Reference CSS: `Sales Cards/sales-flyer.css`
- Use `window.open()` with blob URL for output
- Include `@page` and `-webkit-print-color-adjust: exact` CSS rules

## Data Mapping
| Flyer Field | Source |
|-------------|--------|
| Header h1 | `${category} ${type}` capitalized |
| Product Name | `computer.name` |
| Processor | spec with label "Processor" |
| Memory | spec with label "Memory" or "RAM" |
| Storage | spec with label "Storage" |
| Graphics (desktop) | spec with label "Graphics" |
| Display (laptop) | spec with label "Display" or "Screen Size" |
| Price | `computer.price` |
| Warranty | spec "Parts Warranty" or "Manufacturer Warranty" |
| Diagnostics | spec "Free Diagnostics" |
