# Task: Auth Library & Middleware

## Description
Create `src/lib/supabase-auth.ts` with typed helpers for Supabase Auth operations. Update `src/middleware.ts` to use Supabase sessions for route protection and role-based access control.

## Acceptance Criteria
- [ ] `supabase-auth.ts` created with login, logout, register, password reset helpers
- [ ] Session management with httpOnly cookies for SSR
- [ ] Role-checking utilities (isAdmin, isTechnician, isReceptionist, isCustomer)
- [ ] Middleware updated to check Supabase session
- [ ] Protected routes redirect unauthenticated users
- [ ] Role-based routing enforced (admin routes, employee routes, customer routes)

## Technical Details

**New file: `src/lib/supabase-auth.ts`**
```typescript
// Typed helpers
export async function signIn(email: string, password: string)
export async function signOut()
export async function signUp(email: string, password: string)
export async function resetPassword(email: string)
export async function getSession()
export async function getUserProfile(userId: string)
export function hasRole(profile: UserProfile, roles: Role[])
```

**Middleware updates:**
- Check Supabase session on every request
- Load user_profile for role checking
- Route protection:
  - `/admin/*` requires admin role
  - `/employee/*` requires admin, technician, or receptionist
  - `/portal/*` requires customer role
  - Public routes: `/`, `/login`, `/register`, `/reset-password`

**Files affected:**
- `src/lib/supabase-auth.ts` (new)
- `src/middleware.ts` (modify)
- `src/lib/auth.ts` (deprecate RepairShopr auth)
