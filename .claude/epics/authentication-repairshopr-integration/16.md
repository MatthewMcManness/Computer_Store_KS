# Task: Create Server-Side Session Store

## Description

Create a secure server-side session store that keeps API tokens encrypted and never exposes them to the browser. Uses file-based JSON storage for simplicity (can upgrade to Redis later).

## Acceptance Criteria

- [ ] Create `src/lib/session-store.ts` with session management functions
- [ ] Sessions stored encrypted in `.sessions/` directory (gitignored)
- [ ] Implement `createSession(userData, apiToken)` - returns session ID
- [ ] Implement `getSession(sessionId)` - returns session data or null
- [ ] Implement `deleteSession(sessionId)` - removes session
- [ ] Implement `cleanExpiredSessions()` - garbage collection
- [ ] Session expiry enforced (8 hours)
- [ ] Encryption using SESSION_SECRET environment variable

## Technical Details

### File Location
`src/lib/session-store.ts`

### Session Data Structure
```typescript
interface Session {
  id: string;           // UUID
  userId: number;       // RepairShopr user ID
  email: string;
  name: string;
  role: 'admin' | 'employee' | 'limited';
  apiToken: string;     // Encrypted RepairShopr API token
  createdAt: number;    // Unix timestamp
  expiresAt: number;    // Unix timestamp
}
```

### Storage Format
- Directory: `.sessions/` (at project root, gitignored)
- File per session: `.sessions/{session-id}.json`
- Encrypted content using Node.js crypto with SESSION_SECRET

### Security Considerations
- Use `crypto.createCipheriv` for AES-256-GCM encryption
- Generate unique IV per session
- Store IV with encrypted data
- SESSION_SECRET must be 32 bytes

### Environment Variables
```env
SESSION_SECRET=<32-byte-random-string>
```
