# Task: Intake Wizard Page

## Description
Create the main intake wizard page container at `/admin/intake` with step state management. This is the shell that holds all the step components and manages navigation between them.

## Acceptance Criteria
- [ ] Page accessible at `/admin/intake`
- [ ] Requires employee authentication (redirects to login if not authenticated)
- [ ] Step indicator showing current step (1 of 5, etc.)
- [ ] State management for wizard data (customer, device, ticket info)
- [ ] Navigation: Next, Back buttons
- [ ] Cannot skip steps (enforced progression)
- [ ] Tablet-friendly layout (large touch targets)
- [ ] Consistent with admin page styling (Tailwind)

## Technical Details
- **Location**: `src/app/admin/intake/page.tsx`
- **Components**: `src/components/admin/intake/IntakeWizard.tsx`

### Wizard Steps
1. **Customer Search** - Find existing or choose to create new
2. **Customer Form** - Create new customer (if needed) with password setup
3. **Device** - Select existing or create new device
4. **Ticket** - Enter issue description
5. **Success** - Show ticket number, option to start new intake
