# Task: Intake Wizard Update

## Description
Update the existing intake wizard to require customer portal accounts. After selecting/creating a customer, check if they have a portal account. If not, require the employee to create one before proceeding with the ticket.

## Acceptance Criteria
- [ ] Intake wizard checks for existing portal account after customer selection
- [ ] If no account exists, display account creation form (cannot skip)
- [ ] Email pre-filled from RepairShopr customer record
- [ ] Password setup email sent to customer
- [ ] Visual indicator shows account status throughout intake
- [ ] Account linked to RepairShopr customer record

## Technical Details

**Modified Component:**
- `src/components/admin/intake/IntakeWizard.tsx`

**New Step: Account Check (after customer selection)**
1. Query user_profiles for customer by repairshopr_customer_id
2. If found → show "Portal Account: Active" badge, continue
3. If not found → show account creation form (required)

**Account Creation Form:**
- Email (pre-filled, editable)
- Generate temporary password (user won't see it)
- Submit → Creates Supabase user + user_profile
- Sends "Set your password" email
- Continue to device/ticket creation

**API Updates:**
- `POST /api/customers/portal-account` - Create portal account for existing RepairShopr customer

**Visual Indicators:**
- Green badge: "Portal Account Active"
- Yellow badge: "Creating Portal Account..."
- After creation: "Portal Account Created - Email Sent"

**Files affected:**
- `src/components/admin/intake/IntakeWizard.tsx` (modify)
- `src/app/api/customers/portal-account/route.ts` (new)
