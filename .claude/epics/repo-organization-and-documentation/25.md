# Task: Create Archive Structure and Move HTML/JS/CSS Files

## Description

Create the `_archive/` directory structure and move all deprecated static site files (HTML, JavaScript, CSS) from the root directory. Use `git mv` to preserve git history.

## Acceptance Criteria

- [ ] Create `_archive/` directory with subdirectories
- [ ] Move all deprecated HTML files to `_archive/static-site/`
- [ ] Move all deprecated JS/CSS files to `_archive/static-site/`
- [ ] Create `_archive/README.md` explaining the archive
- [ ] Git history preserved for all moved files
- [ ] Run `bun run build` to verify no breakage

## Technical Details

### Directory Structure to Create
```bash
mkdir -p _archive/{static-site,python-tools,scripts,docs-legacy,misc}
```

### Files to Move to `_archive/static-site/`
```bash
git mv index.html _archive/static-site/
git mv index.html.backup _archive/static-site/
git mv admin-gallery.html _archive/static-site/
git mv admin-gallery.js _archive/static-site/
git mv admin-login.html _archive/static-site/
git mv add-computer.html _archive/static-site/
git mv edit-computer.html _archive/static-site/
git mv computer-form.html _archive/static-site/
git mv facebook-black-friday-post.html _archive/static-site/
git mv MODAL_DEBUG.html _archive/static-site/
git mv script.js _archive/static-site/
git mv style.css _archive/static-site/
git mv config.js _archive/static-site/
```

### Archive README Content
Create `_archive/README.md` explaining:
- What this directory contains
- Why files were archived
- Date of archival
- Note that git history is preserved
