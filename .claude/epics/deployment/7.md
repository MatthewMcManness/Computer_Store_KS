# Task: Configure Render Environment Variables

## Description
Set all required environment variables in the Render dashboard for the production deployment. This can be done in parallel with build fixes (Task 002) since it's dashboard configuration, not code changes.

## Acceptance Criteria
- [ ] `RESEND_API_KEY` set in Render dashboard
- [ ] `ADMIN_PASSWORD` set in Render dashboard (strong password)
- [ ] `NODE_ENV=production` confirmed set
- [ ] Optional: GitHub integration variables set if desired

## Technical Details
- **Required environment variables**:
  ```
  NODE_ENV=production
  RESEND_API_KEY=re_xxxxxxxxx  # From https://resend.com/api-keys
  ADMIN_PASSWORD=<strong-password>  # For /admin/login
  ```
- **Optional environment variables** (for gallery GitHub sync):
  ```
  GITHUB_TOKEN=ghp_xxxxxxxxx
  GITHUB_OWNER=MatthewMcManness
  GITHUB_REPO=Computer_Store_KS
  GITHUB_BRANCH=Computer-Store-KS
  ```
- **Location**: Render Dashboard → computer-store-ks service → Environment

## Dependencies
- [ ] Render account access
- [ ] Resend API key (from Resend dashboard)
- [ ] Admin password (choose a secure one)
