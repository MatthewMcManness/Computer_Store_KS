# Task: Customer Search Step

## Description
Build the first step of the intake wizard where employees search for existing customers or choose to create a new one. Includes search by name, email, or phone with results display.

## Acceptance Criteria
- [ ] Search input field with placeholder text
- [ ] Search triggers on input (debounced, 300ms)
- [ ] Results display: name, email, phone, business (if linked)
- [ ] "Select" button on each result to choose customer
- [ ] "Create New Customer" button always visible
- [ ] "Create New Business Customer" option
- [ ] Loading state during search
- [ ] Empty state when no results found
- [ ] Selecting customer proceeds to Device step (skip Customer Form)
- [ ] Creating new proceeds to Customer Form step

## Technical Details
- **Component**: `src/components/admin/intake/CustomerSearchStep.tsx`
- **API**: `GET /api/repairshopr/customers?q={search}`

### Debounce Implementation
```typescript
// Use useEffect with cleanup to debounce API calls
useEffect(() => {
  const timer = setTimeout(() => {
    if (searchQuery.length >= 2) {
      searchCustomers(searchQuery);
    }
  }, 300);
  return () => clearTimeout(timer);
}, [searchQuery]);
```
