src/lib/session-store.ts
SAFE TO REMOVE - Only used in test files
What it does: File-based encrypted session store that:
  • Stores sessions as encrypted JSON files in .sessions/ directory
  • Uses AES-256-GCM encryption with SESSION_SECRET
  • Provides createSession(), getSession(), deleteSession(), cleanupSessions()
  • Sessions expire after 8 hours
  • Stores userId, email, name, role, and encrypted RepairShopr API token
Why replaced: Session management moved to cookie-based approach in src/lib/session-cookie.ts. Cookie-based sessions are stateless (no server-side storage), work better with serverless deployment, and don't require file system access.
Active imports:
  • src/lib/session-store.test.ts - Unit tests for this file (remove with file)
  • src/lib/auth.test.ts - References in test mocks (will need test update)
Production imports: None. File is exported but never imported in any app code.
Side effects of removal:
  • Delete src/lib/session-store.test.ts at same time
  • May need to update mocks in src/lib/auth.test.ts
  • Can delete .sessions/ directory if it exists locally
Replacement: src/lib/session-cookie.ts
