# Task: Test and validate flyer output

## Description
Validate that generated flyers are visually identical to the existing manually-edited templates. Test both standard and Black Friday variants across different computer types.

## Acceptance Criteria
- [ ] Desktop standard flyer matches `Sales Cards/Desktop_sales-flyer.html`
- [ ] Laptop standard flyer matches `Sales Cards/Laptop_sales-flyer.html`
- [ ] Black Friday desktop flyer has correct theming
- [ ] Black Friday laptop flyer has correct theming
- [ ] All spec fields populate correctly (no "undefined" values)
- [ ] Price displays correctly for standard and Black Friday
- [ ] Warranty displays correctly for standard and Black Friday
- [ ] Flyer prints correctly in Chrome print preview
- [ ] Colors render in print preview (not washed out)

## Test Cases
1. **Desktop + Standard**: Refurbished desktop with standard pricing
2. **Desktop + Black Friday**: Refurbished desktop with Black Friday enabled
3. **Laptop + Standard**: New laptop with standard pricing
4. **Laptop + Black Friday**: Refurbished laptop with Black Friday enabled
5. **Edge case**: Computer with missing optional specs (should not show "undefined")
