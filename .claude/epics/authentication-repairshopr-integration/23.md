# Task: Integration Testing with RepairShopr Accounts

## Description

Perform end-to-end integration testing with actual RepairShopr accounts to verify the complete authentication flow works correctly for all user types.

## Acceptance Criteria

- [ ] Test login with owner account - verify admin role
- [ ] Test login with employee accounts - verify employee role
- [ ] Test login with reception account - verify limited role
- [ ] Verify role-based access restrictions work correctly
- [ ] Test session persistence across page refreshes
- [ ] Test logout clears session completely
- [ ] Test invalid credential handling
- [ ] Test behavior when RepairShopr is slow/unavailable
- [ ] Document any issues found and fixes applied

## Technical Details

### Test Scenarios

**Authentication Tests**
| Test | Expected Result |
|------|-----------------|
| Owner login | Success, role=admin |
| Employee login | Success, role=employee |
| Reception login | Success, role=limited |
| Invalid password | 401 error, clear message |
| Invalid email | 401 error, clear message |
| Empty fields | 400 error, validation message |

**Session Tests**
| Test | Expected Result |
|------|-----------------|
| Page refresh after login | Still authenticated |
| Close and reopen browser | Still authenticated (within 8 hours) |
| Logout | Session cleared, redirected to login |
| Expired session | Redirected to login |

**Role-Based Access Tests**
| Route | admin | employee | limited |
|-------|-------|----------|---------|
| /admin | ✓ | ✓ | ✓ |
| /admin/gallery | ✓ | ✓ | ✗ |
| /admin/gallery/new | ✓ | ✓ | ✗ |
| /admin/settings | ✓ | ✗ | ✗ |

**Error Handling Tests**
| Scenario | Expected Behavior |
|----------|-------------------|
| RepairShopr timeout | Error message, suggest retry |
| Rate limit hit | Clear message with wait time |
| Network failure | Graceful error, no crash |
