# Task: Create RepairShopr API Client

## Description

Create a TypeScript client for the RepairShopr API that handles authentication and provides typed methods for API interactions. This is the foundation for all RepairShopr integration work.

## Acceptance Criteria

- [ ] Create `src/lib/repairshopr.ts` with typed API client
- [ ] Implement `signIn(email, password)` method that calls `POST /sign_in`
- [ ] Implement `getMe(apiToken)` method that calls `GET /me`
- [ ] Handle API errors gracefully with typed error responses
- [ ] Support configurable subdomain via environment variable
- [ ] Include rate limit awareness (180 req/min)

## Technical Details

### File Location
`src/lib/repairshopr.ts`

### API Endpoints to Implement
```typescript
// POST https://{subdomain}.repairshopr.com/api/v1/sign_in
// Body: { email: string, password: string }
// Response: { api_key: string, user: {...} }

// GET https://{subdomain}.repairshopr.com/api/v1/me?api_key={token}
// Response: { user: { id, email, name, role, ... } }
```

### Interface Definitions
```typescript
interface RepairShoprConfig {
  subdomain: string;
  baseUrl?: string; // Optional override for testing
}

interface SignInResponse {
  api_key: string;
  user: RepairShoprUser;
}

interface RepairShoprUser {
  id: number;
  email: string;
  name: string;
  // Role field TBD based on actual API response
}

interface RepairShoprError {
  error: string;
  status: number;
}
```
