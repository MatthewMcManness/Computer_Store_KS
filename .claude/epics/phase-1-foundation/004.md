# Task: Auth Pages

## Description
Build unified authentication pages using Supabase Auth: login (all users), customer registration, and password reset. Replace the existing admin login page.

## Acceptance Criteria
- [ ] `/login` page works for all user types (employees and customers)
- [ ] `/register` page for customer self-registration with email verification
- [ ] `/reset-password` page with email-based reset flow
- [ ] Redirect to appropriate dashboard based on role after login
- [ ] Error handling for invalid credentials, rate limiting, etc.
- [ ] Loading states during auth operations

## Technical Details

**New/Modified Pages:**
- `src/app/(auth)/login/page.tsx` - Unified login
- `src/app/(auth)/register/page.tsx` - Customer registration
- `src/app/(auth)/reset-password/page.tsx` - Password reset request
- `src/app/(auth)/reset-password/confirm/page.tsx` - Set new password

**Login Flow:**
1. User enters email/password
2. Call Supabase signIn
3. Load user_profile to get role
4. Redirect based on role:
   - admin → `/admin`
   - technician → `/employee`
   - receptionist → `/employee`
   - customer → `/portal`

**Registration Flow:**
1. Customer enters email/password
2. Supabase sends verification email
3. Customer clicks link → verified
4. System checks for existing RepairShopr customer
5. Creates user_profile with role='customer'

**Files affected:**
- `src/app/(auth)/login/page.tsx` (new)
- `src/app/(auth)/register/page.tsx` (new)
- `src/app/(auth)/reset-password/page.tsx` (new)
- `src/app/admin/login/page.tsx` (deprecate, redirect to /login)
