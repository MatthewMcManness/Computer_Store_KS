## Acceptance Criteria
- [ ] Render build completes successfully
- [ ] Application accessible at Render URL
- [ ] Health check endpoint returns 200: `/api/health`
- [ ] Admin login works at `/admin/login`
- [ ] Gallery CRUD operations work (add/edit/delete computer)
- [ ] Public gallery displays computers at `/gallery`
- [ ] Contact form submits successfully at `/contact`
- [ ] Notification email received by business
- [ ] Confirmation email received by customer (test email)

## Technical Details
- **Verification checklist**:
  1. Monitor Render build logs until "Deploy live"
  2. Visit `https://<app-name>.onrender.com/api/health`
  3. Test admin flow:
     - Navigate to `/admin/login`
     - Enter ADMIN_PASSWORD
     - Add a test computer with image
     - Verify appears on `/gallery`
     - Edit the computer
     - Delete the computer
  4. Test contact flow:
     - Navigate to `/contact`
     - Fill form with test data
     - Submit and verify success message
     - Check `contact@computerstoreks.com` for notification
     - Check test email inbox for confirmation

- **Rollback plan**: If critical issues found, revert commit and redeploy
