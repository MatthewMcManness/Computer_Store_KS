📋 Executive Summary

This report evaluates VoIP phone systems that can integrate with the Computer Store KS employee portal, support physical desk phones, and provide API access for click-to-call, call history, and real-time event features.

🏆 Recommendation: RingCentral RingEX

RingCentral is the recommended choice for Computer Store KS based on:

  • Comprehensive API - Full REST API with webhooks for call events, call control, and call history
  • Desk Phone Support - Wide selection of Poly and Yealink phones with plug-and-play setup
  • RepairShopr Compatibility - Can work with RepairShopr via Asterisk/FreePBX bridge or custom API integration
  • Scalability - Grows from small team to enterprise without switching platforms
  • Pricing - $20-35/user/month (annual) is competitive for full-featured business VoIP

Runner-up: Dialpad offers excellent AI features and a developer-friendly API at $15-25/user/month, but has more limited desk phone options.

📋 Business Requirements

Based on the original Cytracom integration plan, these are the key requirements for the phone system:

🔌 API Access (Critical)

Public REST API for custom integration with the employee portal. Must support webhooks for real-time events.

📞 Click-to-Call (Critical)

Ability to initiate calls from the employee portal when clicking on customer phone numbers.

📜 Call History API (Critical)

Programmatic access to call logs for displaying on customer pages in the admin portal.

🖥️ Physical Desk Phones

Support for traditional desk phones (Poly, Yealink) for employees who prefer hardware phones.

🎧 Headset/Softphone Support

Web-based or desktop softphone for employees using headsets at their workstations.

📱 Voicemail-to-Email

Automatic voicemail transcription and email notifications for missed calls.

🔔 Real-Time Events

Webhooks or SSE for incoming call notifications to display customer info popup.

💰 Cost-Effective

Reasonable per-user pricing for a small team (3-10 employees).

🔍 Detailed Provider Analysis

RingCentral RingEX ✓ Recommended

RingCentral is the industry leader in business VoIP with the most comprehensive API and extensive hardware support. Their developer platform is mature and well-documented.

Pricing (per user/month, billed annually):
• Core: $20 (basic calling, 100-person video)
• Advanced: $25 (auto call recording, analytics)
• Ultra: $35 (unlimited storage, advanced analytics)

API Capabilities

  • Call Control API - Programmatically make, answer, transfer, park calls
  • Call Log API - Full call history with recordings (15-30 sec delay)
  • Webhooks - Real-time notifications for call events, voicemail, SMS
  • Active Call API - Find calls currently in progress
  • WebRTC SDK - Embed calling directly in web applications
  • 400+ Integrations - Salesforce, HubSpot, Zendesk, etc.

Pros

  • Most comprehensive API in the industry
  • Excellent desk phone selection (Poly, Yealink, Cisco, Avaya)
  • Plug-and-play phone provisioning
  • Device-as-a-Service rental option ($4.50-$26.50/mo)
  • 99.999% uptime SLA
  • 14-day free trial

Cons

  • Higher price than budget options
  • SMS limits (25-200/user/month depending on plan)
  • Complex pricing with potential hidden fees
  • Past reliability issues reported

API Capabilities

Pros

Pricing: Contact for custom quote based on business needs

🔧 RepairShopr Integration Considerations

Current RepairShopr Phone Features

RepairShopr currently supports VoIP integration via Asterisk/FreePBX systems, which provides:

  • Caller ID Popup - Shows customer info when calls come in
  • Customer Matching - Matches 10-digit caller ID to customer records
  • On Ring/On Answer - Configurable notification timing

RepairShopr also integrates with Flowroute for SMS capabilities.

Integration Approach Options

Option A: RingCentral + Custom API Bridge

Build a custom integration layer that:

  • Receives RingCentral webhooks for incoming calls
  • Looks up caller in RepairShopr via their API
  • Displays customer popup in the employee portal
  • Logs call activity to RepairShopr tickets

Option B: Asterisk/FreePBX with RingCentral SIP

Use an Asterisk server as a bridge:

  • RingCentral provides SIP trunking to Asterisk
  • Asterisk handles call events and triggers RepairShopr popups
  • More complex setup but leverages existing RepairShopr integration
