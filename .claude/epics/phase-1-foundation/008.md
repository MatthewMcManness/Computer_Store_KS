# Task: User Migration Script

## Description
Create a migration script to move existing users from the old auth system to Supabase Auth. Migrate `customer_accounts` table entries and existing employee credentials. Send password reset emails to all migrated users.

## Acceptance Criteria
- [ ] Migration script created at `scripts/migrate-users.ts`
- [ ] All existing customer_accounts migrated to Supabase Auth
- [ ] All existing employees migrated with correct roles
- [ ] user_profiles created with RepairShopr ID links preserved
- [ ] Password reset email sent to all migrated users
- [ ] Migration log created for audit trail
- [ ] Rollback plan documented

## Technical Details

**Migration Script: `scripts/migrate-users.ts`**
```typescript
// 1. Backup existing data
// 2. For each customer_accounts row:
//    - Create Supabase Auth user
//    - Create user_profile with role='customer'
//    - Preserve repairshopr_customer_id
//    - Queue password reset email
// 3. For each known employee:
//    - Create Supabase Auth user
//    - Create user_profile with correct role
//    - Preserve repairshopr_user_id
//    - Queue password reset email
// 4. Log all actions
// 5. Verify counts match
```

**Employee Data Source:**
- Currently hardcoded in RepairShopr integration
- Need list of employee emails and roles from business owner

**Migration Strategy:**
1. Run in development first
2. Verify all accounts work
3. Schedule production migration for off-hours
4. Force logout all existing sessions on migration day
5. Users log in with new credentials (via password reset)

**Password Reset Approach:**
- Use Supabase Admin API to create users without passwords
- Immediately trigger password reset email
- Users set their own password on first login

**Files affected:**
- `scripts/migrate-users.ts` (new)
- `scripts/migrate-users-rollback.ts` (new, for emergencies)
