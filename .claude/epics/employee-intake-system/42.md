# Task: RepairShopr API Client

## Description
Create a typed TypeScript client library for interacting with the RepairShopr API. This will be the foundation for all RepairShopr operations including customer search/creation, device management, and ticket creation.

## Acceptance Criteria
- [ ] `src/lib/repairshopr.ts` created with typed API client
- [ ] Customer operations: search, get by ID, create
- [ ] Asset/device operations: list by customer, create
- [ ] Ticket operations: create, get by ID
- [ ] Business/company operations: search, create
- [ ] Proper TypeScript types for all request/response objects
- [ ] Error handling with typed error responses
- [ ] Rate limiting awareness (180 req/min)

## Technical Details
- **File**: `src/lib/repairshopr.ts`
- **Base URL**: `https://{subdomain}.repairshopr.com/api/v1`
- **Auth**: API key in header (`Authorization: Bearer {api_key}`)

### API Endpoints to Implement
```typescript
// Customers
GET  /customers?query={search}     // Search customers
GET  /customers/{id}               // Get customer by ID
POST /customers                    // Create customer

// Assets (Devices)
GET  /customers/{id}/assets        // Get customer's devices
POST /assets                       // Create asset/device

// Tickets
GET  /tickets/{id}                 // Get ticket by ID
POST /tickets                      // Create ticket

// Contacts/Businesses
GET  /contacts?business_name={q}   // Search businesses
POST /contacts                     // Create business contact
```
