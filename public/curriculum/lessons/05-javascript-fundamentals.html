What Is JavaScript?

JavaScript is the programming language of the web. While HTML provides structure and CSS provides styling, JavaScript provides behavior — the ability to make things happen. When a button responds to a click, when a form validates your input, when content loads without a page refresh, when a notification pops up, or when a dashboard updates with real-time data — that is all JavaScript.

JavaScript is unique among programming languages in several ways:

  • It is the only programming language that runs natively in web browsers. Every browser (Chrome, Firefox, Safari, Edge) has a built-in JavaScript engine.
  • With Node.js, JavaScript also runs on servers, making it possible to use one language for both the frontend and backend.
  • It is the most widely used programming language in the world, powering virtually every website.
Analogy: The Nervous System
If HTML is the skeleton (structure) and CSS is the skin and clothing (appearance), then JavaScript is the nervous system and brain. It senses user actions (clicks, keystrokes, scrolling), makes decisions ("Is this form valid?"), sends signals to other parts of the body (fetching data from a server), and controls movement (animations, showing/hiding elements). Without JavaScript, a website is like a mannequin — it looks good but cannot do anything.

Where JavaScript Runs

You can run JavaScript in two places:

1. In the browser (client-side): Open your browser's Developer Tools (F12), click the Console tab, and type:

console.log("Hello from the browser!");
alert("This is JavaScript!");

2. On a server (with Node.js): Create a file called hello.js and run it from the command line:

// hello.js
console.log("Hello from the server!");

// Run with: node hello.js

In this curriculum, we will use JavaScript in both environments. The CSK project runs JavaScript in the browser (for the interactive UI) and on the server (for API routes, database queries, and authentication).

Variables: Storing Data

A variable is a named container that holds a value. Think of it like a labeled box where you can store something and retrieve it later by its label.

Declaring Variables: let and const

// const — for values that will NOT change (use by default)
const shopName = "Computer Store KS";
const maxTickets = 100;
const isOpen = true;

// let — for values that WILL change
let ticketCount = 42;
ticketCount = 43;  // This is allowed with let

let currentStatus = "open";
currentStatus = "diagnosing";  // Reassignment is fine

Rule of thumb: Always use const by default. Only switch to let when you know the value needs to change. This makes your code safer and easier to reason about, because you always know that a const value will not be reassigned unexpectedly.

Never Use var You may see var in older code or tutorials. Do not use it. var has problematic scoping rules that lead to subtle bugs. It was the only option before 2015, but let and const (introduced in ES6/ES2015) fixed those issues. Every modern JavaScript project uses let and const exclusively. The CSK codebase uses const almost everywhere, with let only when reassignment is genuinely needed.

Variable Naming Rules

  • Must start with a letter, underscore (_), or dollar sign ($)
  • Can contain letters, numbers, underscores, and dollar signs
  • Are case-sensitive (userName and username are different variables)
  • Use camelCase for variables and functions: firstName, ticketCount, isLoggedIn
  • Use UPPER_SNAKE_CASE for constants that represent fixed, known values: MAX_RETRIES, API_BASE_URL
  • Choose descriptive names: customerEmail is much better than ce or x

Data Types

Every value in JavaScript has a type that determines what kind of data it is and what you can do with it. JavaScript has eight data types, but you will primarily work with the first six:

String

Text data, enclosed in quotes:

const name = "Computer Store KS";   // Double quotes
const city = 'Topeka';              // Single quotes
const greeting = `Hello, ${name}!`; // Template literal (backticks)

// String properties and methods
console.log(name.length);           // 17 (number of characters)
console.log(name.toUpperCase());    // "COMPUTER STORE KS"
console.log(name.toLowerCase());    // "computer store ks"
console.log(name.includes("Store")); // true
console.log(city.startsWith("Top")); // true
console.log(name.slice(0, 8));      // "Computer" (characters 0-7)
console.log(name.replace("KS", "Kansas")); // "Computer Store Kansas"
console.log("  hello  ".trim());    // "hello" (removes whitespace)

Number

Both integers and decimals use the same type:

const price = 45.99;
const quantity = 3;
const total = price * quantity;    // 137.97

// Special numeric values
const infinity = Infinity;
const notANumber = NaN;            // Result of invalid math like 0 / 0

// Useful number methods
console.log(Math.round(4.7));      // 5
console.log(Math.floor(4.9));      // 4 (always rounds down)
console.log(Math.ceil(4.1));       // 5 (always rounds up)
console.log(Math.max(10, 20, 5));  // 20
console.log(Math.min(10, 20, 5));  // 5
console.log(Math.random());        // Random decimal between 0 and 1
console.log(total.toFixed(2));     // "137.97" (string with 2 decimal places)

// Converting strings to numbers
const input = "42";
const num = Number(input);         // 42 (as a number)
const parsed = parseInt("42px");   // 42 (ignores trailing text)
const decimal = parseFloat("3.14");// 3.14

Boolean

A value that is either true or false:

const isOpen = true;
const isClosed = false;
const hasPassword = true;

// Booleans from comparisons
const isExpensive = price > 100;   // false (45.99 is not > 100)
const isMatch = name === "Computer Store KS"; // true

null and undefined

// undefined — variable declared but never assigned a value
let middleName;
console.log(middleName);           // undefined

// null — intentionally empty (you set it to "nothing")
let selectedTicket = null;         // "No ticket is selected yet"
selectedTicket = { id: 42 };       // Now a ticket is selected
selectedTicket = null;             // Ticket deselected

The difference is subtle but important: undefined means "no value was ever assigned," while null means "a value was intentionally set to nothing." Think of undefined as an empty mailbox that has never received mail, and null as a mailbox you deliberately emptied.

Object

A collection of key-value pairs (covered in detail below):

const customer = {
  name: "Jane Smith",
  email: "jane@example.com",
  phone: "(785) 555-1234"
};

Array

An ordered list of values (covered in detail below):

const services = ["Virus Removal", "Diagnostics", "Data Recovery"];

BigInt and Symbol

These are specialized types you will rarely need as a beginner. BigInt handles integers larger than Number can safely represent. Symbol creates unique identifiers. We mention them for completeness, but you can safely ignore them for now.

Checking Types

console.log(typeof "hello");       // "string"
console.log(typeof 42);            // "number"
console.log(typeof true);          // "boolean"
console.log(typeof undefined);     // "undefined"
console.log(typeof null);          // "object" (this is a known JavaScript bug!)
console.log(typeof {});            // "object"
console.log(typeof []);            // "object" (arrays are objects)

// To check if something is an array:
console.log(Array.isArray([]));    // true

Operators

Arithmetic Operators

const a = 10;
const b = 3;

console.log(a + b);   // 13  (addition)
console.log(a - b);   // 7   (subtraction)
console.log(a * b);   // 30  (multiplication)
console.log(a / b);   // 3.333... (division)
console.log(a % b);   // 1   (modulo — the remainder of 10 / 3)
console.log(a ** b);  // 1000 (exponentiation — 10 to the power of 3)

// Increment and decrement
let count = 0;
count++;               // count is now 1
count--;               // count is now 0
count += 5;            // count is now 5 (shorthand for count = count + 5)
count -= 2;            // count is now 3
count *= 3;            // count is now 9

Comparison Operators

// ALWAYS use strict equality (=== and !==)
console.log(5 === 5);       // true  (same value AND same type)
console.log(5 === "5");     // false (different types)
console.log(5 !== 3);       // true  (not equal)

// AVOID loose equality (== and !=) — causes surprising behavior
console.log(5 == "5");      // true  (DANGEROUS — type coercion)
console.log(0 == false);    // true  (DANGEROUS)
console.log("" == false);   // true  (DANGEROUS)

// Relational operators
console.log(10 > 5);        // true
console.log(10 >= 10);      // true
console.log(3 < 7);         // true
console.log(3 <= 2);        // false
Always Use === (Strict Equality) The loose equality operator (==) performs type coercion, which leads to bizarre results like "" == false being true. Always use the strict equality operator (===) which checks both value and type. The entire CSK codebase uses strict equality exclusively. This is a non-negotiable best practice in modern JavaScript.

Logical Operators

const isAdmin = true;
const isLoggedIn = true;
const isBanned = false;

// AND (&&) — both must be true
console.log(isAdmin && isLoggedIn);          // true
console.log(isAdmin && isBanned);            // false

// OR (||) — at least one must be true
console.log(isAdmin || isBanned);            // true
console.log(isBanned || false);              // false

// NOT (!) — inverts the boolean
console.log(!isAdmin);                       // false
console.log(!isBanned);                      // true

// Practical example
if (isLoggedIn && isAdmin && !isBanned) {
  console.log("Access granted to admin panel");
}

Control Flow

if / else if / else

Conditional statements let your program make decisions:

const ticketStatus = "diagnosing";

if (ticketStatus === "new") {
  console.log("Ticket needs to be assigned to a technician.");
} else if (ticketStatus === "diagnosing") {
  console.log("Technician is investigating the issue.");
} else if (ticketStatus === "repairing") {
  console.log("Repair is in progress.");
} else if (ticketStatus === "ready_for_pickup") {
  console.log("Call the customer — their computer is ready!");
} else {
  console.log(`Status: ${ticketStatus}`);
}

// Nested conditions
const customer = { name: "Jane", silverPlan: true };
const repairCost = 120;

if (customer.silverPlan) {
  if (repairCost <= 150) {
    console.log("Repair is covered by Silver Plan!");
  } else {
    console.log("Repair exceeds Silver Plan coverage.");
  }
} else {
  console.log(`Total cost: $${repairCost}`);
}

Ternary Operator

A concise way to write simple if/else statements:

// Syntax: condition ? valueIfTrue : valueIfFalse
const status = isOpen ? "Open" : "Closed";
const message = ticketCount > 0 ? `${ticketCount} tickets` : "No tickets";
const greeting = customer.silverPlan ? "Welcome, Silver member!" : "Welcome!";

// Used often in React for conditional rendering:
// {isLoggedIn ? <Dashboard /> : <LoginPage />}

switch Statement

When you have many conditions based on a single value, switch can be cleaner than a chain of if/else:

const statusCode = 404;

switch (statusCode) {
  case 200:
    console.log("OK — request succeeded");
    break;
  case 301:
    console.log("Moved Permanently — update your bookmarks");
    break;
  case 404:
    console.log("Not Found — the page does not exist");
    break;
  case 500:
    console.log("Internal Server Error — something broke on the server");
    break;
  default:
    console.log(`Unexpected status code: ${statusCode}`);
}

Loops

Loops let you repeat an action multiple times. This is essential for processing lists of data.

for Loop

// Classic for loop: initialize; condition; update
for (let i = 0; i < 5; i++) {
  console.log(`Iteration ${i}`);  // 0, 1, 2, 3, 4
}

for...of Loop

The preferred way to iterate over arrays in modern JavaScript:

const services = ["Diagnostics", "Virus Removal", "Data Recovery"];

for (const service of services) {
  console.log(`We offer: ${service}`);
}
// Output:
// We offer: Diagnostics
// We offer: Virus Removal
// We offer: Data Recovery

while and do...while Loops

// while — checks condition BEFORE each iteration
let attempts = 0;
while (attempts < 3) {
  console.log(`Attempt ${attempts + 1}`);
  attempts++;
}

// do...while — checks condition AFTER each iteration (runs at least once)
let input;
do {
  input = "valid"; // In real code, this would prompt the user
} while (input === "");
Which Loop to Use
  • for...of — Use for iterating over arrays (most common). Clean and readable.
  • for — Use when you need the index number or need custom iteration logic.
  • while — Use when you do not know in advance how many times to loop.
  • do...while — Rare. Use when the loop must run at least once.
  • Array methods (.map(), .filter(), etc.) — Often better than loops. Covered below.

Functions

A function is a reusable block of code that performs a specific task. Functions are the building blocks of all programs. You define a function once and then call it as many times as you need.

Function Declaration

function greet(name) {
  return `Hello, ${name}! Welcome to Computer Store KS.`;
}

// Calling the function
const message = greet("Jane");
console.log(message);  // "Hello, Jane! Welcome to Computer Store KS."

// Function with multiple parameters
function calculateTotal(price, quantity, taxRate) {
  const subtotal = price * quantity;
  const tax = subtotal * taxRate;
  return subtotal + tax;
}

const total = calculateTotal(45.99, 2, 0.065);
console.log(total.toFixed(2));  // "97.95"

Function Expression

// A function stored in a variable
const greet = function(name) {
  return `Hello, ${name}!`;
};

console.log(greet("Bob"));  // "Hello, Bob!"

Arrow Functions

Arrow functions are a shorter syntax introduced in ES6. They are the most common function syntax in modern JavaScript and React codebases:

// Full arrow function
const greet = (name) => {
  return `Hello, ${name}!`;
};

// Concise body (when the function is a single expression)
// No curly braces needed, return is implicit
const greet = (name) => `Hello, ${name}!`;

// Single parameter — parentheses optional
const double = n => n * 2;

// No parameters — empty parentheses required
const getTimestamp = () => new Date().toISOString();

// Multiple parameters
const add = (a, b) => a + b;

// Usage
console.log(greet("Jane"));    // "Hello, Jane!"
console.log(double(21));       // 42
console.log(add(10, 5));       // 15

Default Parameters

const createTicket = (title, priority = "normal", assignee = "unassigned") => {
  return { title, priority, assignee };
};

console.log(createTicket("Screen broken"));
// { title: "Screen broken", priority: "normal", assignee: "unassigned" }

console.log(createTicket("Data loss", "urgent", "Mike"));
// { title: "Data loss", priority: "urgent", assignee: "Mike" }
CSK Connection The CSK codebase uses arrow functions almost exclusively. Every React component, every API route handler, every utility function uses arrow syntax. For example, the blog API route starts with export async function GET(request: NextRequest) (using declaration syntax for the Next.js export), but internal helper functions use arrows: const formatDate = (date) => .... Understanding arrow functions is essential for reading any modern JavaScript or TypeScript codebase.

Objects

An object is a collection of related data and functionality, stored as key-value pairs (also called "properties"). Objects are fundamental to JavaScript — nearly everything in the language is an object or behaves like one.

// Creating an object
const customer = {
  id: 42,
  firstName: "Jane",
  lastName: "Smith",
  email: "jane@example.com",
  phone: "(785) 555-1234",
  silverPlan: true,
  visits: 12,

  // A method (function inside an object)
  getFullName() {
    return `${this.firstName} ${this.lastName}`;
  }
};

// Accessing properties
console.log(customer.firstName);      // "Jane" (dot notation)
console.log(customer["email"]);       // "jane@example.com" (bracket notation)
console.log(customer.getFullName());  // "Jane Smith"

// Dynamic property access (bracket notation required)
const field = "phone";
console.log(customer[field]);         // "(785) 555-1234"

// Modifying properties
customer.visits = 13;
customer.lastVisit = "2026-02-01";   // Adding a new property

// Checking if a property exists
console.log("email" in customer);     // true
console.log("address" in customer);   // false

Nested Objects

const ticket = {
  id: 1234,
  subject: "Laptop won't boot",
  customer: {
    name: "Jane Smith",
    email: "jane@example.com"
  },
  status: {
    custom: "diagnosing",
    repairshopr: "In Progress"
  },
  createdAt: "2026-02-01T10:30:00Z"
};

// Accessing nested properties
console.log(ticket.customer.name);     // "Jane Smith"
console.log(ticket.status.custom);     // "diagnosing"

Destructuring Objects

Destructuring lets you extract properties from an object into individual variables. This is used everywhere in modern JavaScript and React:

const customer = {
  firstName: "Jane",
  lastName: "Smith",
  email: "jane@example.com",
  silverPlan: true
};

// Without destructuring
const firstName = customer.firstName;
const email = customer.email;

// With destructuring (much cleaner)
const { firstName, lastName, email, silverPlan } = customer;
console.log(firstName);  // "Jane"
console.log(email);      // "jane@example.com"

// Destructuring with renaming
const { firstName: first, lastName: last } = customer;
console.log(first);      // "Jane"

// Destructuring in function parameters
const displayCustomer = ({ firstName, lastName, silverPlan }) => {
  const badge = silverPlan ? " [Silver]" : "";
  return `${firstName} ${lastName}${badge}`;
};
console.log(displayCustomer(customer));  // "Jane Smith [Silver]"

Arrays

An array is an ordered list of values. Arrays are essential for working with collections of data — lists of customers, tickets, services, products, and more.

// Creating arrays
const services = ["Diagnostics", "Virus Removal", "Data Recovery"];
const prices = [45, 75, 120, 99];
const mixed = ["hello", 42, true, null, { name: "Jane" }];

// Accessing elements (zero-indexed)
console.log(services[0]);    // "Diagnostics" (first element)
console.log(services[1]);    // "Virus Removal" (second element)
console.log(services[2]);    // "Data Recovery" (third element)
console.log(services.length); // 3 (number of elements)

// Modifying arrays
services.push("OS Installation");     // Add to end
services.unshift("Consultation");     // Add to beginning
const removed = services.pop();       // Remove from end (returns removed item)
const first = services.shift();       // Remove from beginning

Essential Array Methods

Array methods are the workhorses of JavaScript programming. These are used constantly in real-world code:

.map() — Transform every element

const prices = [45, 75, 120, 99];

// Create a new array with each price increased by 10%
const newPrices = prices.map(price => price * 1.10);
console.log(newPrices);  // [49.5, 82.5, 132, 108.9]

// Transform objects
const customers = [
  { firstName: "Jane", lastName: "Smith" },
  { firstName: "Bob", lastName: "Jones" }
];

const names = customers.map(c => `${c.firstName} ${c.lastName}`);
console.log(names);  // ["Jane Smith", "Bob Jones"]

.filter() — Keep only matching elements

const tickets = [
  { id: 1, status: "new", priority: "high" },
  { id: 2, status: "diagnosing", priority: "normal" },
  { id: 3, status: "new", priority: "urgent" },
  { id: 4, status: "completed", priority: "normal" }
];

// Get only new tickets
const newTickets = tickets.filter(ticket => ticket.status === "new");
console.log(newTickets.length);  // 2

// Get high-priority tickets
const urgent = tickets.filter(t => t.priority === "urgent" || t.priority === "high");
console.log(urgent.length);  // 2

.find() — Find the first matching element

const ticket = tickets.find(t => t.id === 3);
console.log(ticket);  // { id: 3, status: "new", priority: "urgent" }

// Returns undefined if not found
const missing = tickets.find(t => t.id === 999);
console.log(missing);  // undefined

.reduce() — Combine all elements into one value

const prices = [45, 75, 120, 99];

// Sum all prices
const total = prices.reduce((sum, price) => sum + price, 0);
console.log(total);  // 339

// Count tickets by status
const statusCounts = tickets.reduce((counts, ticket) => {
  counts[ticket.status] = (counts[ticket.status] || 0) + 1;
  return counts;
}, {});
console.log(statusCounts);  // { new: 2, diagnosing: 1, completed: 1 }

.forEach() — Do something with each element (no return value)

services.forEach(service => {
  console.log(`Service available: ${service}`);
});

.includes() — Check if an element exists

const statuses = ["new", "diagnosing", "repairing", "completed"];
console.log(statuses.includes("diagnosing"));  // true
console.log(statuses.includes("deleted"));     // false

.sort() — Sort elements

const names = ["Charlie", "Alice", "Bob"];
names.sort();  // ["Alice", "Bob", "Charlie"] (alphabetical)

// Sort numbers (requires a comparison function!)
const numbers = [30, 5, 100, 15];
numbers.sort((a, b) => a - b);  // [5, 15, 30, 100] (ascending)
numbers.sort((a, b) => b - a);  // [100, 30, 15, 5] (descending)

Chaining Array Methods

One of the most powerful patterns in JavaScript is chaining methods together:

const tickets = [
  { id: 1, subject: "Won't boot", status: "new", priority: "high" },
  { id: 2, subject: "Slow performance", status: "completed", priority: "low" },
  { id: 3, subject: "Blue screen", status: "new", priority: "urgent" },
  { id: 4, subject: "No WiFi", status: "diagnosing", priority: "normal" }
];

// Get subject lines of open high-priority tickets
const urgentSubjects = tickets
  .filter(t => t.status !== "completed")          // Remove completed
  .filter(t => t.priority === "high" || t.priority === "urgent")  // Only high/urgent
  .map(t => t.subject);                            // Extract subjects

console.log(urgentSubjects);  // ["Won't boot", "Blue screen"]

The Spread Operator (...)

The spread operator (...) "spreads" an array or object into its individual elements. It is used extensively in modern JavaScript:

// Spread in arrays
const basics = ["Diagnostics", "Virus Removal"];
const premium = ["Custom Build", "Data Recovery"];
const allServices = [...basics, ...premium];
// ["Diagnostics", "Virus Removal", "Custom Build", "Data Recovery"]

// Copy an array (without reference)
const original = [1, 2, 3];
const copy = [...original];
copy.push(4);
console.log(original);  // [1, 2, 3] — unchanged!

// Spread in objects
const defaults = { priority: "normal", status: "new" };
const ticket = {
  ...defaults,
  subject: "Broken screen",
  priority: "high"       // Overrides the default
};
// { priority: "high", status: "new", subject: "Broken screen" }

// Immutable update (common in React)
const updatedCustomer = {
  ...customer,
  visits: customer.visits + 1,
  lastVisit: new Date().toISOString()
};

Template Literals

Template literals use backticks (`) instead of quotes and allow string interpolation — embedding expressions directly inside a string:

const name = "Jane";
const tickets = 3;

// Old way (string concatenation) — ugly and error-prone
const message = "Hello, " + name + "! You have " + tickets + " open tickets.";

// Modern way (template literal) — clean and readable
const message = `Hello, ${name}! You have ${tickets} open tickets.`;

// You can put ANY expression inside ${}
const total = `Total: $${(45.99 * 3).toFixed(2)}`;
const status = `Status: ${isOpen ? "Open" : "Closed"}`;

// Multi-line strings (great for HTML)
const html = `
  <div class="ticket">
    <h3>${ticket.subject}</h3>
    <p>Status: ${ticket.status}</p>
  </div>
`;
CSK Connection Template literals, destructuring, spread operators, and array methods (.map(), .filter(), .find()) are used in virtually every file in the CSK codebase. React components use .map() to render lists of tickets, customers, and services. API routes use destructuring to extract request parameters. Object spread is used to merge default options with user-provided ones. These are not "advanced" features — they are the everyday vocabulary of modern JavaScript.

Error Handling: try/catch

Errors are inevitable in programming. When something goes wrong (a network request fails, data is in an unexpected format, a file is missing), you need to handle the error gracefully instead of letting your program crash.

// Basic try/catch
try {
  // Code that might throw an error
  const data = JSON.parse("this is not valid JSON");
} catch (error) {
  // Handle the error
  console.error("Failed to parse JSON:", error.message);
}

// try/catch/finally
try {
  const result = riskyOperation();
  console.log("Success:", result);
} catch (error) {
  console.error("Error:", error.message);
} finally {
  // This runs NO MATTER WHAT — whether it succeeded or failed
  console.log("Cleanup complete");
}

// Throwing your own errors
const validateEmail = (email) => {
  if (!email) {
    throw new Error("Email is required");
  }
  if (!email.includes("@")) {
    throw new Error("Invalid email format");
  }
  return true;
};

try {
  validateEmail("not-an-email");
} catch (error) {
  console.log(error.message);  // "Invalid email format"
}
Errors Are Your Friends New programmers often fear errors, but they are actually incredibly helpful. An error message tells you exactly what went wrong and where. Get comfortable reading error messages — they contain the line number, file name, and a description of the problem. The better you get at reading errors, the faster you will become at fixing code.

Key Takeaways

  • JavaScript is the programming language of the web, running in browsers (client-side) and on servers (Node.js). It makes web pages interactive.
  • Use const by default for variables that will not be reassigned, and let for those that will. Never use var.
  • JavaScript has eight data types: string, number, boolean, null, undefined, object, array (technically an object), BigInt, and Symbol.
  • Always use strict equality (===) instead of loose equality (==) to avoid type coercion bugs.
  • Arrow functions (const fn = (x) => x * 2) are the standard function syntax in modern JavaScript. Use function declarations for top-level exports.
  • Objects store key-value pairs. Arrays store ordered lists. Both support destructuring for clean variable extraction.
  • Array methods (.map(), .filter(), .find(), .reduce()) are essential tools for transforming and querying data. Chain them together for powerful data pipelines.
  • Template literals (`Hello, ${name}!`), the spread operator (...), and destructuring are modern JavaScript features used constantly in professional codebases.
