# Task: Update Auth Library for RepairShopr Integration

## Description

Modify `src/lib/auth.ts` to use RepairShopr authentication instead of (or alongside) the current password-based auth. Support dual-mode for migration.

## Acceptance Criteria

- [ ] Update `src/lib/auth.ts` to integrate RepairShopr client and session store
- [ ] Implement `authenticateWithRepairShopr(email, password)` function
- [ ] Update `createSession()` to store full session data including role
- [ ] Update `isAuthenticated()` to validate against session store
- [ ] Add `getCurrentUser()` function to get user info from session
- [ ] Support dual-mode via `AUTH_MODE` environment variable
- [ ] Maintain backward compatibility with existing cookie name

## Technical Details

### File Location
`src/lib/auth.ts`

### New/Modified Functions
```typescript
// New functions
export async function authenticateWithRepairShopr(
  email: string,
  password: string
): Promise<{ success: boolean; error?: string; user?: UserSession }>;

export async function getCurrentUser(): Promise<UserSession | null>;

export function getAuthMode(): 'repairshopr' | 'legacy';

// Modified functions
export async function createSession(user: UserSession): Promise<string>;
export async function isAuthenticated(): Promise<boolean>;
export async function destroySession(): Promise<void>;
```

### UserSession Type
```typescript
interface UserSession {
  userId: number;
  email: string;
  name: string;
  role: 'admin' | 'employee' | 'limited';
}
```

### Dual-Mode Logic
```typescript
const AUTH_MODE = process.env.AUTH_MODE || 'repairshopr';

// If AUTH_MODE === 'legacy', use old password check
// If AUTH_MODE === 'repairshopr', use RepairShopr API
```

### Environment Variables
```env
AUTH_MODE=repairshopr  # or 'legacy'
LEGACY_ADMIN_PASSWORD=<current-password>  # Keep for fallback
```
